# German-only content, professional-first framing

Despite the professional-first goal (recruiters/clients/peers, who might expect English), the site is German-only, not bilingual. A language switcher was rejected because it roughly doubles content-writing and maintenance effort for a personal site with a small, largely local (DACH) intended audience. This is a deliberate deviation from the "English for widest reach" default and should not be "fixed" by adding English without revisiting the audience assumption.
