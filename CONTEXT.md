# Personal Homepage (michael-moeckel.de)

A personal site presenting Michael as a programmer first, with a secondary section for spare-time activities.

## Language

**Landing Page**:
The site's root route (`/`). Mostly professional content — name, tagline, short intro — with a small teaser link into Spare Time. Not a neutral hub; it's weighted toward the Profession Page.
_Avoid_: Home page, index

**Profession Page**:
The page presenting Michael's work: bio, core skills, a few highlighted projects, and contact links. Deliberately minimal — not a full CV or case-study portfolio.
_Avoid_: Resume, CV, portfolio, about page

**Spare Time**:
The nav grouping for non-professional content. A category, not a single page — it contains one Hobby Page per hobby.
_Avoid_: Hobbies (as a page name), personal page

**Hobby Page**:
A top-level page under Spare Time dedicated to one hobby (e.g. Astronomy, Sports). Static content plus zero or more Log Entries.
_Avoid_: Category page, activity page

**Log Entry**:
A single dated update within a Hobby Page (e.g. an observation, a race). Fields: date, title, body, optional photos, optional tags. Generic across all Hobby Pages — not hobby-specific.
_Avoid_: Post, blog entry, update
